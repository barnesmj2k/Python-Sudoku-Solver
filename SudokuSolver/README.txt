The program reads input through standard system input.
An error will occur if sudoku input is not a 9x9 list of integers without space seperations.
See inputs 1, 2, and 3 for examples.

Run program with the following commands...

For Powershell terminal:
    Get-Content input1.txt | python Sudoku.py

For cmd terminal:
    python Sudoku.py < input1.txt
